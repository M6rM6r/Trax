# Trax portfolio & Play Console screenshots

Demo UI mockups for store listing and portfolio (not live app captures).  
Regenerate anytime:

```bash
python scripts/generate_portfolio_screenshots.py
```

## Folders

| Folder                 | Use                                                                     |
| ---------------------- | ----------------------------------------------------------------------- |
| `play-console/`        | **1080×1920** marketing frames — best for Google Play phone screenshots |
| `play-console-device/` | **1080×1920** device-only (no headline text)                            |
| `phone/`               | Raw UI + device-framed PNGs for decks / Behance / Dribbble              |
| `tablet/`              | Wide dashboard mock for portfolio                                       |
