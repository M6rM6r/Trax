# دليل المستخدم - المتوسط الشهري للإنتظار

## نظرة عامة

### ما هو المتوسط الشهري للإنتظار؟

تقرير شهري يعرض **متوسط الوقت** الذي ينتظره العملاء قبل وصول السائق لكل منطقة في المملكة.

### لماذا هذا التقرير مهم؟

- 📊 **متطلب وزاري**: مطلوب من وزارة النقل
- 📈 **تحسين الأداء**: متابعة جودة الخدمة في كل منطقة
- 📍 **تحديد المناطق**: معرفة المناطق التي تحتاج تحسين
- 💾 **الأرشفة**: تحميل البيانات للتقارير الشهرية

### ما الذي يظهر في التقرير؟

- اسم المنطقة (مثال: الرياض، جدة)
- متوسط وقت الانتظار (مثال: 5.23 دقيقة)
- الفترة الزمنية للبيانات

---

## الوصول للصفحة

### المسار
```
الصفحة الرئيسية → متطلبات وزارة النقل → المتوسط الشهري للإنتظار
```

### 💡 ملاحظة عند فتح الصفحة

عند فتح الصفحة لأول مرة، ستجد:

```
ℹ️ هذه البيانات الخاصة بالشهر الماضي (فبراير)، وتكون محددة بشكل تلقائي.
   ويمكنكم تغيير المدة الزمنية والمدينة حسب الاحتياج.
```

**معنى ذلك**:
- ✅ البيانات جاهزة للشهر الماضي
- ✅ التواريخ محددة تلقائياً
- ✅ يمكنك التعديل حسب حاجتك

## تطبيق الفلاتر

### 1️⃣ فلتر الفترة الزمنية

**استخدمه لـ**:
- عرض بيانات شهر معين
- مقارنة فترات زمنية مختلفة
- إعداد تقارير شهرية أو ربع سنوية

**الخطوات**:
1. انقر على قسم "الفترة الزمنية"
2. اختر **من تاريخ** (مثال: 01/01/2026)
3. اختر **إلى تاريخ** (مثال: 31/01/2026)
4. انقر "تطبيق الفلتر"

⚠️ **تنبيهات**:
- تاريخ النهاية لا يمكن أن يسبق تاريخ البداية
- كلا التاريخين **مطلوبان** لعرض البيانات
- النظام يمنع اختيار تواريخ مستقبلية

---

### 2️⃣ فلتر المدن

**استخدمه لـ**:
- عرض مدينة محددة
- مقارنة عدة مدن
- تركيز التقرير على منطقة جغرافية

#### أ. عرض كامل المملكة

**الطريقة**: لا تختر أي مدينة

**النتيجة**:
```
📊 البيانات المعروضة:
- الرياض
- جدة
- الدمام
- مكة المكرمة
- المدينة المنورة
- ... جميع المناطق
```

---

#### ب. عرض مدينة واحدة

**الخطوات**:
1. انقر قسم "المدن"
2. انقر على مربع الاختيار
3. ابحث عن المدينة (مثال: الرياض)
4. انقر على المدينة
5. انقر "تطبيق الفلتر"

**النتيجة**:
```
📊 البيانات المعروضة:
- الرياض فقط
```

---

#### ج. عرض عدة مدن

**الخطوات**:
1. انقر قسم "المدن"
2. انقر على مربع الاختيار
3. اختر المدينة الأولى (مثال: الرياض) ✓
4. اختر المدينة الثانية (مثال: جدة) ✓
5. اختر المدينة الثالثة (مثال: الدمام) ✓
6. انقر "تطبيق الفلتر"

**النتيجة**:
```
📊 البيانات المعروضة:
- الرياض
- جدة
- الدمام

❌ البيانات المخفية:
- مكة المكرمة
- المدينة المنورة
- ... باقي المناطق
```

💡 **ملاحظة**: المدن المحددة تظهر كـ badges أسفل مربع الاختيار، يمكنك إزالة أي مدينة بالنقر على (X).

---

### 3️⃣ عرض وإلغاء الفلاتر النشطة

#### الفلاتر النشطة

بعد تطبيق الفلتر، تظهر badges زرقاء تعرض الفلاتر الحالية:

```
[من تاريخ: 01/01/2026 ✕]  [إلى تاريخ: 31/01/2026 ✕]  [المدن: الرياض, جدة ✕]
```

#### إزالة فلتر واحد

انقر على (✕) في الـ badge الذي تريد إزالته.

⚠️ **ملاحظة**: إزالة "من تاريخ" سيزيل أيضاً "إلى تاريخ" تلقائياً.

#### إلغاء جميع الفلاتر

انقر على زر **"إلغاء الفلتر"** → ستعود الصفحة للإعدادات الافتراضية (الشهر الماضي).

## تحميل البيانات

### خطوات التحميل

#### 1️⃣ تطبيق الفلاتر

أولاً، حدد البيانات المطلوبة:
```
الفترة الزمنية: 01/01/2026 - 31/01/2026
المدن: الرياض، جدة (أو اتركها فارغة لكامل المملكة)
```

#### 2️⃣ تحديد البيانات

**خيار أ: تحديد الكل**

1. انقر على مربع **"تحديد الكل"**
2. ستُحدد جميع البطاقات (يظهر إطار أزرق حول كل بطاقة)

**خيار ب: تحديد بطاقات محددة**

1. انقر على مربع الاختيار في البطاقات المطلوبة فقط
2. مثال: الرياض ✓ + جدة ✓ + الدمام ✓

**العداد**:
```
تحديد الكل (3 من 13)
```
- 3 = عدد البطاقات المحددة
- 13 = إجمالي البطاقات المعروضة

---

#### 3️⃣ تنزيل الملف

1. انقر على زر **"تحميل المحدد (3)"** 📥
2. سيتم تنزيل ملف CSV تلقائياً
3. اسم الملف: `monthly-waiting-data-{timestamp}.csv`

**مثال**:
```
monthly-waiting-data-1709384567890.csv
```

---

### ⚠️ رسائل التنبيه

#### لم يتم تحديد فترة زمنية
```
❌ "الرجاء تحديد الفترة الزمنية أولاً"
```
**الحل**: حدد "من تاريخ" و "إلى تاريخ" وطبّق الفلتر.

#### لم يتم اختيار بيانات
```
❌ "الرجاء اختيار بيانات للتحميل"
```
**الحل**: حدد بطاقة واحدة على الأقل قبل التحميل.

#### فشل التحميل
```
❌ "فشل تحميل البيانات. الرجاء المحاولة مرة أخرى"
```
**الحل**: تحقق من الاتصال بالإنترنت وأعد المحاولة.
