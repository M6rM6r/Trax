# متطلبات وزارة النقل (Ministry Requirements)

## نظرة عامة

قسم متطلبات وزارة النقل يحتوي على التقارير والبيانات المطلوبة من قبل وزارة النقل السعودية لمراقبة وتتبع أداء منصة حلول نقل.

---

## الأقسام المتوفرة

### 1. المتوسط الشهري للإنتظار

- **المسار:** `/ministryRequirements/monthlyWaitingAverage`
- **الوصف:** عرض متوسط أوقات انتظار العملاء حسب المدن خلال فترة زمنية محددة
- **الميزات:**
  - فلترة البيانات حسب الفترة الزمنية
  - فلترة حسب المدن (أو عرض بيانات كامل المملكة)
  - تحميل البيانات المحددة بصيغة CSV
  - عرض البيانات في بطاقات تفاعلية
  - تحديد افتراضي للشهر الماضي

**الوثائق:**
- 📖 [التوثيق التقني](./monthly-waiting-average.md) - للمطورين
- 👤 [دليل المستخدم](./MONTHLY_WAITING_USER_GUIDE_AR.md) - للمستخدمين

**API Endpoints:**
- `GET /wasl/provinces` - جلب قائمة المدن
- `GET /wasl/waiting-averages` - جلب بيانات المتوسط الشهري
- `GET /wasl/waiting-averages?download=true` - تحميل البيانات كـ CSV

## ملاحظات عامة

1. **نظام WASL:** جميع API endpoints تحت مسار `/wasl/`
2. **التقارير الشهرية:** البيانات يتم عرضها بشكل شهري افتراضيًا
3. **التوافق مع الوزارة:** البيانات متوافقة مع متطلبات وزارة النقل السعودية
4. **التحميل:** إمكانية تحميل البيانات بصيغة CSV للأرشفة والتقارير
5. **الشفافية:** عرض البيانات بطريقة واضحة وسهلة الفهم
