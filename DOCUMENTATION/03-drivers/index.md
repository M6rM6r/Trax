## API Endpoints المشتركة

### إنشاء السائقين

| Endpoint | Method | الوصف |
|----------|--------|-------|
| `/drivers` | `POST` | إنشاء سائق جديد (الخطوة الأولى) |
| `/drivers/setService` | `POST` | تحديد بيانات الخدمة/المركبة |
| `/drivers/updateDocuments` | `POST` | رفع المستندات |
| `/drivers/checkWaslValidity` | `POST` | التحقق من وصل |

## خطوات التسجيل المشتركة

### الخطوة 0: البيانات الأساسية (مشتركة لجميع الأنواع)

**المكون:** `components/shared/AddDriver/AddBasic.tsx`

| الحقل | النوع | مطلوب | الوصف |
|-------|-------|-------|-------|
| `profile_image` | `File` | لا | صورة الملف الشخصي (JPG/PNG, max 5MB) |
| `name` | `string` | نعم | الاسم الكامل (3+ حروف، بدون أرقام) |
| `gender` | `select` | نعم | الجنس (ذكر/أنثى) |
| `mobile` | `phone` | نعم | رقم الجوال |
| `country_code` | `string` | نعم | كود الدولة |
| `email` | `email` | لا | البريد الإلكتروني |

**قواعد التحقق:**
```typescript
name: Yup.string()
  .required("الاسم مطلوب")
  .matches(/^(?!\s)(?!.*\s$)[^\d]+$/, "الاسم لا يمكن أن يحتوي على أرقام")
  .min(3, "الاسم يجب ان يكون مكون من 3 حروف على الاقل")

gender: Yup.string().required("الجنس مطلوب")

mobile: Yup.string().required("رقم الجوال مطلوب")

country_code: Yup.string().required("رقم الجوال مطلوب")
```
